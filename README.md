# 🐕 Gassi Weg

**Moderne Angular-Website für einen Gassi-Service** – betrieben von einem 18-jährigen (Finn).

Frisch, bunt, Pop-Art-inspiriert und komplett auf Deutsch.

## Features

- **Home** mit großem Pop-Art-Hund (SVG), Hero-Section und Feature-Cards
- **Preise** – drei klare Pakete (30 / 60 / 90 Min)
- **Anfrage** – Reactive Form mit Validierung und Erfolgsmeldung
- **Impressum** – Platzhalter-Angaben (bitte anpassen!)
- Responsive Design, sticky Navbar, mobile Burger-Menü
- Pop-Art Farbschema (Gelb, Cyan, Magenta, harte Schatten, Ben-Day-Dots)

## Tech Stack

- Angular 19 (Standalone Components)
- TypeScript
- Reactive Forms
- Custom CSS (kein Bootstrap nötig)
- Google Fonts: Bangers + Nunito

## Starten

```bash
# Dependencies installieren
npm install

# Development-Server starten
npm start
# → http://localhost:4200

# Production Build
npm run build
```

2. **Preise** – in `preise.component.ts` ändern
3. **Name / Branding** – überall „Finn“ und „Gassi Weg“ ersetzen
